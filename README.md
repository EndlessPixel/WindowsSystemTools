# WindowsSystemTool
一个基于 PyQt5 开发的 Windows 系统快捷管理工具。

## 简介
集成了常用的 Windows 系统管理命令，方便一键执行操作，
自用、学习、娱乐均可。

## 功能
- 远程桌面管理
- 安全防护开关
- 系统服务启停
- 系统清理优化
- 进程管理
- 启动项设置
- 网络配置
- Windows 更新管理
- 时区/时间同步
- 视觉效果调整
- 安全扫描
- 系统还原点创建

## 说明
本工具为个人学习项目，仅用于快捷执行系统命令。
专业场景请使用 Dism++ 等成熟工具。

## 运行环境
- Python 3.x
- PyQt5
- psutil
- pywin32

## 启动方式
```bash
pip install -r requirements.txt
python main.py
```
